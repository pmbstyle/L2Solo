🖥️ **Introducing the L2Solo desktop launcher**

Our first desktop launcher is available for Windows, Linux and macOS, including Intel and Apple Silicon Macs. It brings the web launcher's server controls together with server installation, updates, searchable settings and file repair in one application.

🚀 **Easier setup**

- Install and run your local server without Git, npm or a separate Node.js installation. Choose a folder and the launcher downloads the server and prepares the required runtime and C4 geodata.
- Connect an existing server or install into a separate folder for a fresh world. Open your server folder directly from the app.
- Verify server files and repair missing or damaged geodata from the Updates page.

🎮 **Your world at a glance**

- Start and stop the server from the Home page. Stopping the server or closing the launcher lets it save and shut down gracefully.
- See the server version, status, uptime, login address, bot population and online player count in one place.
- Open World Observer with one click, check recent activity and read live server logs in the Console.

⚙️ **Settings without editing files**

- Adjust progression rates, maximum level, bot population, PvP aggression and other server options through grouped settings with search and explanations. Saved changes apply on the next server start.
- Configure the optional AI provider, endpoint, model and API key in one section, alongside World Observer and connection settings.

🔄 **Updates from the app**

- Server and launcher updates are checked automatically in the background at startup and every five minutes. You can also check manually and read release notes inside the launcher.
- Download server updates while playing, then stop the server to apply them. Updates preserve your world, local settings and manual backups.
- Before applying a server update, the launcher snapshots the world and its history. If the updated server fails its initial startup verification, the previous server and world are restored.
- Windows Setup and Linux AppImage builds support in-app launcher updates. On macOS, download the matching DMG, quit the launcher and replace the app. Windows portable and Linux DEB builds use a replacement installer.

💾 **Backups & world management**

- Create, restore and delete named world backups while the server is stopped. Existing saved games from the web launcher appear here too when you connect the same server folder.
- Reset bots, players or the entire world with explicit confirmation. Saved backups are kept, so you can restore a world you backed up earlier.

The original web launcher remains available. Existing Git checkouts can be started and configured in the desktop app; use a separate installation folder for launcher-managed server updates.
