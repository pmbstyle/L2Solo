Install and update L2Solo through the desktop launcher.

- Server packages include production dependencies and declare the exact Node.js runtime they require.
- Updates preserve local settings, geodata, manual backups and world/history databases.
- The launcher verifies startup and both login/game listeners before opening the updated world to players.
- Failed migration startup restores the previous server and matching database pair. Database paths and identities are checked before migrations.
- Live population reports distinguish playing bots and players from static bots.

Download the launcher installer for your platform from the attached files. Preview versions are intended for a separate test world.
